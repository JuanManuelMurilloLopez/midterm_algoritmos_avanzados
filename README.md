# midterm_algoritmos_avanzados
Repositorio para el proyecto de la materia de Análisis y Diseño de Algoritmos Avanzados

# Dependencias

	pip install numpy pandas scikit-learn 

## 1. `main.py` — Predicción Individual y Explicabilidad

### Propósito
Demostrar el funcionamiento completo del sistema explicable sobre un solo enfrentamiento, integrando predicción, explicación algorítmica, análisis de equidad (fairness) y benchmarking computacional.

### Ejecución
```bash
python main.py
```

## 2. `test.py` — Evaluación Algorítmica y Comparación, Imcorporando PageRank

### Propósito
Evaluar el comportamiento del sistema sobre múltiples ligas y temporadas, comparando algoritmos clásicos y analizando rendimiento, escalabilidad y robustez.

### Ejecución
```bash
python test.py
```

## 3. `ml.py` —Línea Base con Random Forest

### Propósito
Introducir una referencia basada en el algoritmo de random forest para contextualizar el rendimiento de los algoritmos explicables.
### Ejecución
```bash
python ml.py
```
